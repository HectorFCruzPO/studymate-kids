# StudyMate Kids

A bilingual, offline-first educational Android
application for children ages 4–7.

## Product Vision

Create a safe, fun, and engaging learning experience
where children develop foundational skills through
interactive activities and gamified learning journeys.

## Core Learning Areas

- Numbers & Counting
- Letters & Sounds
- Colors & Shapes
- Animals & Discovery

## Key Features

- English and Spanish with spoken instructions
- Fully offline Android application
- Multiple child profiles and avatar selection
- Gamified learning journeys with stars and gold coins
- Parent dashboard and progress tracking
- No ads, in-app purchases, or external game redirects

## Technology Stack (Planned)

- React Native and Expo
- TypeScript
- SQLite for local data storage
- Git and GitHub for version control

## Project Status

Phase 1: Product planning and environment setup.
